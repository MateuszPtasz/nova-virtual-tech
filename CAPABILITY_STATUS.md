## Isolation rule

Independent agents do not inherit NOVA's:
- personality;
- private memory;
- repository state;
- provider bindings;
- authority;
- schedules.

Shared platform infrastructure does not make two agents the same principal.

## Evidence rule

A capability is not promoted here merely because:
- code exists;
- a test passed locally;
- a plan says it should work;
- another agent proved a similar path.

External side effects require external/readback evidence. Ambiguous side effects are reconciled rather than blindly repeated.

## Disclosure boundary

This repository intentionally does not publish:
- private prompts/instructions;
- private NOVA memory/self state;
- private tenant data;
- credentials/tokens;
- protected repository bindings;
- sensitive control-plane implementation details.

The goal is public truth, not public replication of the private machinery.
